# 验证记录

日期：2026-11-17。以下记录区分了计划、模拟节点、真实本地后期工具和真实 GPU 生成。

## 已执行的验证

- 完整 Python 测试：91 项通过。覆盖真实兼容模型请求的协议形状（使用 HTTPX 替身）、计划 schema/一次修复、详细提示词与分工报告、N worker 分配、容量限制、断线恢复和合成。
- 三台本地 HTTP 模拟节点：通过真实命令行发起任务、下载各自结果、用真实 Pillow 合成，并在同一运行目录恢复；三项素材任务分配到三台节点，恢复没有再次提交。节点返回合成测试图，不运行扩散模型。
- 真实 FFmpeg/FFprobe：生成一秒视频与音轨，将透明图层叠加到视频，解码检查画面像素、尺寸、时长和音轨保留。
- 多层合成：检查透明区域、灰阶遮罩与原 alpha 相乘、空遮罩拒绝、比例与落点、叠放顺序；全部素材成功前不输出成品。
- 提交与恢复：保存原始 `prompt_id` 后继续查历史；POST 响应丢失时停止并要求核对远端队列，不盲目重发。计划、配置或工作流变化时拒绝复用原目录。
- 中文排版：通过测试字体检查完整码点覆盖、缺字拒绝、多行文字和越界；视频后期失败时清理部分成品。
- 三份人工示例通过 `CreativePlan` 校验，Markdown 由同一报告生成器输出。`demo` 仅导出计划，不把人工示例当成 LLM 结果。
- Agent Skill 通过官方 `quick_validate.py`；另一执行者独立按 Skill 完成护肤品竖版海报的计划，保留指定尺寸与两段逐字文案，正确拆出橄榄枝图层，没有为四台机器凑出多余对象，也没有启动出图。
- Ruff 静态检查、Python wheel/sdist 构建、打包资源与必要许可检查。

独立审查发现并关闭了三项缺陷：多行文字锚点不兼容、缺中文字形静默绘制、视频编码超时留下部分成品。真实 HTTP 测试另发现系统 SOCKS 代理会干扰局域网连接，已将 ComfyUI worker 请求设为默认直连并加入回归检查。

## 运行边界

这是单次命令驱动的轻量规划器与执行器。`capacity` 限制一次 Runner 内的并发，不提供跨进程全局槽位；已提交任务恢复时绑定原 worker，不自动迁移或重复执行。恢复前仍检查节点可用性。它不包含集群控制台、自动扩缩容或跨机器显存合并。

GitHub Actions 在 Python 3.11、3.13 上执行测试、构建与离线示例。线上运行状态以仓库最新 Actions 记录为准。
