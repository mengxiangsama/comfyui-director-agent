# ComfyUI Director

把用户的一句话补成可见、可检查的画面，并让分别生成的素材能够合成。

## 选择输出

- 用户只要提示词：直接用当前 Agent 生成，读 [提示词与分工](references/directing.md)。不要求 LLM API，不启动 ComfyUI。
- 用户要 JSON、可执行计划或多台机器分工：再读 [计划格式](references/plan-contract.md)，按 `CreativePlan 1.0` 生成计划。仓库存在时优先用实际模型/schema 校验。
- 用户已要求执行出图：再读 [执行说明](references/execution.md)，使用已配置的工作流与服务器。需求或凭证缺失时，先完成不依赖它们的创作计划。

## 必须保留的约定

1. 保留用户指定的主体、数量、用途、画幅、风格和原文标题。非关键细节可合理补全，列出影响画面的假设。
2. 先定义共享风格、色板、光源方向、视角和布局，再分别写背景与主体提示词；中英文须表达同一画面。
3. 支持一张背景、主要前景及 `extra_layers` 附加前景，按顺序本地合成。N 台机器按角色和容量接任务，不要求一层一台；不为用满机器擅加对象。合成需要实际 alpha 或 mask，不能把“透明背景”几个字当成已得到透明素材。
4. 精确标题、价格和 Logo 采用素材或独立文字层。没有指定标题时，不擅自加文案。
5. 视频基于无字合成图再描述运动，保持主体外观和布局连续。精确文字在视频生成后叠加，需要字体与 ffmpeg/ffprobe。帧数、尺寸须适配实际视频工作流。
6. 提示词、计划校验、人工示例导出、真实 GPU 出图和视频结果分别报告。只生成计划时，不声称已经调用 ComfyUI；不把验收清单写成已通过的自动评分。

默认用简洁中文说明方案，再给可直接复制的详细提示词或用户要求的 JSON。只有缺失信息会改变关键结果时才追问；不要在每轮末尾固定要求确认。
